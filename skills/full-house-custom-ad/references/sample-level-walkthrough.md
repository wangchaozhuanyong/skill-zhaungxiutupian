# 样片级连续空间漫游规则

样片级连续空间漫游是最高级别的装修短视频目标。它追求的不是图片好看，而是观看者感觉摄影机正在进入并穿过一个真实住宅空间。

## 识别标准

当参考视频具备以下特征时，判定为样片级连续空间漫游：

1. 视频几乎无硬切，或者硬切极少且不破坏连续看房感。
2. 镜头在同一住宅空间内持续移动。
3. 有横移、推进、轻微转向或稳定器 walkthrough 感。
4. 前景家具、柜体边缘、吊灯、沙发、电视墙产生连续视差。
5. 地面反光、吊顶线条、墙面边界持续引导镜头。
6. 字幕很少，主要让观众看空间。
7. 调色低饱和、柔和、克制、高级。
8. 空间比例、材质、灯光在运动中保持一致。

## 必须拒绝的错误做法

禁止把以下内容说成同款样片级漫游：

- 6 到 8 张图片轮播。
- 静态图放大缩小。
- 普通 Ken Burns 推拉。
- 图片之间加转场。
- 低真实感程序化 3D。
- 不连续的多空间拼接。
- 材质、灯光和空间比例跳变的 AI 图片序列。

## 正确执行路径

如果有真实连续视频：

- 做后期调色、节奏、字幕、音乐和导出。
- 不要转成图片方案。
- 先生成 `continuity_report.md`、关键帧拼图和最大跳变帧对；基础视觉门禁通过后，仍需有效人工空间语义复核文件才能称为 L4。

如果有专业 3D 漫游导出：

- 做剪辑、调色、字幕、音乐和成片包装。
- 保留连续空间路径和真实视差。
- 仍需确认同一空间、材质、灯光和比例在运动中不跳变。

如果有 AI 连续视频能力：

- 必须是单条连续 AI video，或已通过连续性检查的同一空间连续视频。
- 输出连续视频生成提示词、时间码、镜头路径、材质一致性规则和负面词。
- 明确每段镜头如何保持同一空间、同一材质、同一光照和同一比例。

如果只有多个独立 AI video clip：

- 默认判定为 L2：AI 分段空间漫游。
- 必须生成连续性检查报告。
- 未通过同一空间、连续视差、少硬切、材质灯光一致检查和有效人工空间语义复核文件前，不得称为真正 walkthrough 或样片级连续空间漫游。

## L4 验收边界

脚本的抽帧、帧差、硬切风险和最大跳变帧对只能作为基础视觉门禁。它能发现明显硬切、画面跳变和空间断裂风险，但不能自动证明电视墙、沙发、柜体、地面、灯光和真实 3D 视差全部一致。

因此：

- `l4_gate_result: candidate` 只表示 L4 候选，不等于最终 L4。
- `manual_semantic_review_file` 未配置、文件不存在、源视频 hash 不匹配、样片级专项评分低于 85、逐项勾选不完整或复核结论未通过时，不得最终标注为样片级连续空间漫游；`manual_semantic_review_passed=true` 不能单独作为 L4 依据。
- validator 的抽帧、帧差、硬切风险和最大跳变帧对只提供基础视觉证据，不自动证明电视墙、沙发、餐桌、柜体、地面、灯光和空间比例语义一致；最终 L4 必须人工查看关键帧证据并完成复核文件。
- 若人工复核发现换房、材质跳变、比例异常、视差不真实或镜头路线断裂，必须降级为 L3、L2 或 L1。

如果只有静态图：

- 先说明不能达到真正样片级连续 walkthrough。
- 再生成 Style Bible。
- 再生成 3 到 5 张同一空间连续关键帧。
- 再做降级版伪空间漫游。
- 输出时必须标注为“样片风格伪漫游”，不得称为真正 walkthrough 或同款样片级漫游。

如果用户明确不提供素材、要求系统自己生成或只是做测试片：

- 启用自动原创素材生成模式。
- 默认进入 Codex 交互式生成路径，不要求 `OPENAI_API_KEY` / `FAL_KEY`。
- 当前会话可生成图片时，先设计 Style Bible 和同一空间静态关键帧，再本地渲染 L1 样片风格伪漫游。
- 只有用户明确选择 API 无人值守模式，或当前会话具备视频生成工具时，才尝试单条连续 AI video；成功后只能进入 L3 candidate，L4 仍需报告、视觉证据、专项评分和人工复核。
- 多个独立 AI video clip 成功后只能标 L2。
- gpt-image-2 / 静态关键帧成功后只能标 L1。
- API 无人值守后端全部不可用时输出 `GENERATOR_NOT_READY`，但这只表示脚本后端未就绪；不得第一轮要求用户上传 `source_video`，也不得阻止 Codex 交互式 L1 方案。

## 必须先输出的诊断

当用户上传参考视频，或说“我要做出这种视频”“像这个一样”“不要图片轮播”“像走进房子一样”“3D 漫游”“一镜到底”“walkthrough”“连续空间感”“为什么做不出来”时，必须先输出：

```text
参考视频类型：
当前 capability level：
它为什么不是普通图片展示：
它的镜头路径：
它的空间结构：
它的调色和灯光：
它的字幕和节奏：
要达到同款观看体验必须具备什么素材或后端：
当前能否直接做：
如果不能，缺什么：
可执行的最高质量替代方案：
```

## 样片级时间码模板

13 秒样片级连续漫游：

```text
0.0-2.0 秒：
从餐厅或玄关侧进入，镜头中低机位，慢速横移，先看到客餐厅尺度。

2.0-4.0 秒：
经过餐桌、餐边柜、吊顶线条，建立空间连续感。

4.0-7.0 秒：
电视墙、岩板、深灰柜体、隐藏灯带成为主视觉。

7.0-9.5 秒：
镜头继续横移，利用沙发、茶几、吊灯或柜体边缘制造前景视差。

9.5-13.0 秒：
回到完整横厅大景，客厅、餐厅、电视墙、落地窗同时成立，高级收尾。
```

这是判断和沟通模板，不是固定路线。每次必须根据用户素材、音乐和原创设计概念重新设计镜头路径。

## 意式轻奢样片风格公式

空间：
145㎡左右大横厅、客餐厅一体、电视墙、沙发区、餐边柜、落地窗。

材质：
深灰柜体、暖灰岩板、玻璃柜门、金属线条、地面高反光、隐藏灯带。

镜头：
中低机位、慢速横移、轻微转向、少切或不切、稳定器感。

调色：
低饱和、暖灰、亮部柔和、暗部干净、地面反光清楚。

字幕：
少字或无字，不要大字压画面。
